# Fixtures

Test inputs for FlowSentinel.

Rules for everything in this directory:

- **Synthetic or publicly safe only.** Fixtures are generated by scripts in
  `scripts/` or built byte by byte in tests. Never commit captures of real
  networks, even your own.
- **No secrets.** No credentials, tokens, cookies or personal data, real or fake-looking.
- **Reproducible.** Every binary fixture must be regenerable from a script in this repository.

`.gitignore` blocks `*.pcap`/`*.pcapng` everywhere except under `fixtures/`.
That is deliberate, so a real capture can't be committed by accident.
