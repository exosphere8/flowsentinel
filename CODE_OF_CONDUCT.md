# Code of conduct

FlowSentinel welcomes contributions from everyone. To keep the project a good place to work:

- **Be respectful.** Disagree about ideas, not people. No harassment, insults, discrimination,
  or unwelcome sexual attention, in any project space: issues, pull requests, discussions,
  reviews or other channels.
- **Be constructive.** Explain the reasons behind a request or a review comment, and assume good
  faith.
- **Respect the project's purpose.** FlowSentinel is for defensive analysis of networks you are
  authorized to inspect. Do not use project spaces to share captures, credentials or personal
  data you have no right to share, or to seek help attacking systems.

## Reporting

Report unacceptable behaviour to the maintainer, [@exosphere8](https://github.com/exosphere8),
privately. For example, use a private security advisory if no other private channel is
available. Reports are handled confidentially.

## Enforcement

The maintainer may edit or remove contributions, and warn, or temporarily or permanently ban
anyone whose behaviour breaks this code. The response depends on how serious the behaviour is
and whether it is repeated.
